# Focus Redirect

A Chrome extension (Manifest V3) that sends distracting sites to a back-to-work page. The site list is editable, and blocking can follow an optional schedule.

## Install

1. Download or clone this repository.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and choose this folder.

Edit the blocked sites and the schedule on the extension's **Options** page.
